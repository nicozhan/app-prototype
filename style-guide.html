卡片标准 · C3

所有列表卡片统一使用 .acard：2px 整圈描边（按严重度取色）+ 同色扩散光晕（P0 最强，逐档递减）+ 实心等级徽章 + 软底状态胶囊 + 标题 + 属性 chips + 底部（等宽时间 + 实心按钮）。卡片底色统一纯白，让描边与光晕承担「严重度」的表达。

自上而下四层：等级徽章 + 状态胶囊（同一行，左右分置）→ 标题 → 属性 chips → 时间 + 操作。

0 0 0 3px rgba(122,132,168,.07) / 0 6px 16px rgba(36,52,200,.06)
光晕是 C3 的核心语言：列表里靠光晕强弱一眼分级。P0 最强，P1 减半，P2 只保留极淡的一圈——避免整页发红光。工单优先级映射：P1 → p0（红），P2 → p1（橙）。

C3 的状态不再是「裸文字 + 色点」，而是同色系 8% 软底胶囊，与实心等级徽章形成「实心 / 空心」的层次对比。

约束

新页面卡片一律用 .acard，不新增卡片变体
严重度只取 p0 / p1 / p2 三档，颜色与光晕由类决定，禁止内联改色
光晕强度必须逐档递减，不可所有档位同强度（整页发光会失去分级意义）
空值（—）不渲染为 chip
Figma 1:1 复刻页保持不变
vend.css 只追加新类，不改动既有规则
