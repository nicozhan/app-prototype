卡片标准 · C4

所有列表卡片统一使用 .acard：整圈描边（1.5px，按严重度/优先级取色）+ 顶部 4px 色条 + 严重度标签 + 状态色点 + 标题 + 标签 chips + 底部（等宽时间 + 操作）。新页面一律沿用此结构。

结构示例

.acard.p0
P0 · 严重 待处理
柜内温度过高
设备告警 SN0020301 上海 A 店 JAVA
2026/10/25 14:40查看 →

严重度 / 优先级配色

描边 + 色条
P2 · 提示 已完成
低严重度 · 浅蓝灰描边
P1 · 警告 处理中
中严重度 · 橙色描边
P0 · 严重 待处理
高严重度 · 红色描边
工单优先级同样映射：P1 → p0（红），P2 → p1（橙）。

状态配色

色点 + 文字
待处理s-todo
处理中s-doing
等待反馈s-warn
待认领 / 已完成s-claim / s-done
已关闭 / 待审核s-closed

用法

HTML 骨架
<a class="acard p0" href="...">
  <div class="astrip"></div>      <!-- 顶部色条 -->
  <div class="ain">
    <div class="atop">
      <span class="alvl"><span class="sdot"></span>P0 · 严重</span>
      <span class="ast2 s-todo"><span class="tdot"></span>待处理</span>
    </div>
    <div class="atitle">标题</div>
    <div class="achips">…chips…</div>
    <div class="afoot">
      <span class="atime">时间</span><span class="abtn">查看 →</span>
    </div>
  </div>
</a>
双按钮场景用 .aacts + .abt2（主）/ .abt2.ghost（次）替代 .afoot。

约束

新页面卡片一律用 .acard，不新增卡片变体
严重度只取 p0 / p1 / p2 三档，颜色由类决定
空值（—）不渲染为 chip
Figma 1:1 复刻页（登录/我的/首页/商品/设备/补货）保持不变
vend.css 只追加新类，不改动既有规则
